At a glance

MovieFlow (movieflow.ai) is an AI filmmaking studio: you write an idea, and it builds the story, characters, scenes, and film. It uses 13 models from other companies (Seedance, Kling, Veo, MiniMax, Vidu, Nano Banana, GPT Image, Seedream, and others), each best at a different task. This project brings together what each model does, its limits, and when to use it in a guide and a data file. Just read the page to use it; if you want, you can run the chooser in the terminal with Python, without installing anything.

What it is

A model hub, not a single model

In 2025, MovieFlow was marketed as “a free film up to 10 minutes long.” Today, it charges for credits and has become a dashboard where you choose the engine for each scene.

🎬 9 video models

Seedance 2.5, 2.0 and Fast, Kling 3.0 and 2.6, MiniMax H3, Vidu Q3 Pro, Veo 3, and MovieFlow 2.0 Ultra.

🖼️ 4 image models

Nano Banana Pro and 2, GPT Image 2, and Seedream 5.0 for characters, keyframes, posters, and storyboards.

🧭 When to use each one

A “use when” line for each model, its limits, and the sources. When sources conflict, the page says so.

Words used on the cards

Lip-sync — the character's mouth moves with the speech.
Multi-shot — several shots (camera cuts) generated at once with the same character.
Shot and reverse shot — the camera alternates between two people talking.
Keyframe — the main image that defines what a character or scene will look like.
Storyboard — a sequence of scene drawings made before the film.
Reference — a photo, video, or audio file you send the model to copy a face, style, or movement.
720p, 1080p, 2K, 4K — resolution: the higher it is, the sharper the image (and generally the more expensive).
Motion Control — the model copies movement from one of your videos (dance, gesture).
Agent V2 — MovieFlow mode where AI builds the entire film from your idea.

How it works

From idea to film, for less

A credit-saving workflow: start with a cheap draft, then use an expensive model only for the scene that matters.

Idea in one sentence→ Agent builds the story and storyboard→ Draft in MovieFlow 2.0 Ultra→ Character image (Nano Banana Pro)→ Final scene in the right model→ Adjust one detail (MiniMax H3)
Step-by-step guide

Use the guide and chooser

The easiest way is to use the Which to use buttons on this page, with no installation. To run the chooser in the terminal: Python 3 (on Windows, use python instead of python3) and Git—or download the ZIP from GitHub (Code button → Download ZIP). It runs on your computer, with no account or key.

1

Download the project

The repository contains data for the 13 models (modelos.json) and the chooser (escolher.py).

git clone https://github.com/inematds/movieflow-modelos.git
cd movieflow-modelos
2

Describe the scene and see the recommended model

Describe the scene in a few words (the tool understands Portuguese keywords). The chooser compares them with each model's tags and shows the top 3, along with “use when” guidance and limits.

python3 escolher.py "conversa entre dois personagens em anime"  # 1. Vidu Q3 Pro  2. Kling 3.0  3. Veo 3
python3 escolher.py "cartaz com texto do filme"  # 1. Nano Banana Pro  2. GPT Image 2
3

View the list or a model's details

The list filters by video or image; the details show highlights, limits, and sources.

python3 escolher.py --lista --tipo video
python3 escolher.py --modelo kling-3.0
4

In MovieFlow, switch models by scene

Create an account at movieflow.ai (it comes with trial credits), make a draft with the cheap model, then redo only the important scenes with the recommended model. For a character that appears in multiple scenes, create an image of them first and use it as a reference.

https://movieflow.ai  # Agent V2 → idea → language, duration, format → Create
5

Keep the data up to date

Models change quickly. When MovieFlow changes its list, edit modelos.json and rebuild the page.

python3 montar_guia.py  # generates guia/index.html from modelos.json
What it costs

No longer free and unlimited

What can be confirmed today, and what cannot yet.

🎟️ Signup credits

New accounts get credits to try it (100 credits, according to a November 2026 pricing directory). It's a trial, not unlimited use.

⚡ US$0.008 per second

Price announced on the site itself for MovieFlow 2.0: 5 seconds of video for about 4 cents.

📅 Standard plan

US$19 per month with 1,800 credits and 1080p downloads without a watermark (Kingy directory, November 2026). Credits reset every 31 days.

The credit cost for each model is only visible when signed in, and the site's plan table loads with JavaScript. Check movieflow.ai/pricing before subscribing.
